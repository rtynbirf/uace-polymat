# Security Policy — UACE × PML / POLYMAT

## Поддерживаемые версии

| Продукт | Версия | Поддержка |
|---|---|---|
| POLYMAT UNIFIED | v34.x | да |
| TXT-EXPORT | 1.0.x | да (полигон) |
| Cookie Vault | 3.0.x | да |

## Что гарантируется каноном

- **0 сетевых запросов** во всех компонентах (статический валидатор ищет fetch/XHR/WebSocket/remote-скрипты на каждый релиз).
- Шифрование Cookie Vault: AES-256-GCM + PBKDF2-SHA256 600k; неверный PIN и подмена шифротекста отклоняются аутентификацией GCM.
- Каждый релиз сопровождается протоколом машинных проверок (`verification/`) и SHA-256 дайджестами (GitHub считает их для артефактов Release автоматически, автор дополнительно публикует `checksums.txt`).

## Как сообщить об уязвимости

Используйте приватные Security Advisories этого репозитория (вкладка Security → Report a vulnerability).
Публичные issue для уязвимостей не создавать до выпуска исправления.

## Гигиена секретов (КРИТИЧНО)

- Токены GitHub / API-ключи / пароли **никогда** не коммитятся в репозиторий.
- Токены, вставленные в чат-сессию, считаются скомпрометированными: их нужно **отозвать и выпустить новые** после настройки (GitHub → Settings → Developer settings → Tokens), желательно fine-grained с минимальными правами (Contents: read/write на нужный репозиторий).
- Для CI используются только встроенные `secrets.*` GitHub Actions.
